# Sugar & Steam

Concept demo website for a fictional desserts, coffee and waffles restaurant, made by SAL Digital.
It is not a real business. Orders are built on the page and sent as a WhatsApp message.

Want a site like this for your restaurant? https://saldigital.co/lp/restaurants/
